# maimai攻略ノート

個人用のmaimaiプレイ記録・譜面確認PWAアプリです。

## 使い方（公開）

1. このリポジトリの中身（`index.html` 等）をリポジトリ直下に置く
2. Settings → Pages で Branch を `main`、フォルダを `/ (root)` にして Save
3. `https://ユーザー名.github.io/リポジトリ名/` をスマホのSafariで開く
4. 共有ボタン →「ホーム画面に追加」

## データの持ち方

- **曲・譜面（songs.json）**：このリポジトリのファイルとして管理します。アプリ内の「＋ 新しい曲を作る」で曲を作り、譜面画面の「編集」をONにしてリング上をタップするとノーツを配置できます（PC・スマホどちらのブラウザからでも操作できます）。ただし、アプリ内で作った内容はその端末のブラウザにしか保存されないので、他の端末にも反映したい場合は「songs.jsonを書き出す」でダウンロードしたファイルをこのリポジトリの`songs.json`に上書きしてpush（またはGitHub上で直接編集）してください。
- **記録・日課・目標**：スマホのブラウザ内（localStorage）だけに保存されます。端末をまたいでは同期されません。

## 譜面編集の使い方

1. 譜面ページで曲を選ぶ（または「＋ 新しい曲を作る」で新規作成）
2. ヘッダーの「編集」をONにする
3. ノーツの種類（タップ／タッチ／スライド）と、必要なら色（既定＝赤／右手＝青／左手＝緑）を選ぶ
4. 再生・巻き戻し・スクラブバーで曲の中の狙った時間に合わせる
5. リング上のボタンをタップすると、その時間にノーツが置かれる
   - **タップ**：8つのボタンのどれかをタップ
   - **タッチ**：8つのボタンか、中心の丸をタップ（中心＝センタータッチ扱い）
   - **スライド**：始点のボタン→終点のボタンの順に2回タップ。長さ（秒）は編集パネルの数値で調整
6. 一通り作ったら「songs.jsonを書き出す」からダウンロードし、GitHubの`songs.json`を置き換える

## songs.json の書き方（直接編集する場合）

曲＋難易度の組み合わせごとに1つのオブジェクトです。同じ曲でも難易度が違えば別々のオブジェクトとして追加します。

```json
{
  "id": "曲を識別するユニークな文字列（英数字とハイフンでOK）",
  "title": "曲名",
  "difficulty": "BASIC / ADVANCED / EXPERT / MASTER / Re:MASTER のいずれか",
  "level": "表示用のレベル（例：13+）",
  "bpm": 175,
  "duration": 120,
  "notes": [
    { "id": "ID", "type": "tap",   "time": 12.5, "button": 3, "color": "red" },
    { "id": "ID", "type": "touch", "time": 13.0, "button": 0, "color": "blue" },
    { "id": "ID", "type": "slide", "time": 14.0, "from": 2, "to": 6, "duration": 0.6, "color": "green" }
  ]
}
```

- `duration` は曲の長さ（秒）。譜面画面のスクラブバーの範囲に使われます
- `notes[].time` は曲の先頭からの秒数（小数可）
- `button` は1〜8（12時の位置を1として時計回り）。タッチノーツで`0`を指定すると中心（センタータッチ）
- `type`が`slide`のときは`button`の代わりに`from`（始点）・`to`（終点）・`duration`（スライドが終わるまでの秒数）を使う
- `color` は `"red"`（既定）/ `"blue"`（右手）/ `"green"`（左手）

**注意：一度使い始めた曲の `id` は変更しないでください。** 記録（プレイ履歴）は `id` で曲と紐付いているため、`id`を変えたり消して作り直したりすると、スマホ側に保存されている過去の記録がその曲と紐付かなくなります。曲を追加するときは配列に新しいオブジェクトを追加するだけでOKです。
